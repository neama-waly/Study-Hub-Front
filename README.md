# STUDY HUB 
A full-stack web application designed to help students organize study materials, manage notes, track progress, and upload course resources efficiently.

---
Key Features

- User Authentication : Secure user signup and login (JWT / Sessions).
- Notes & Study Management: Create, update, and manage personal study notes.
- Material Uploads: Upload and manage study resources and documents.
- Progress Dashboard: Track overall study progress and coursework completion.
- Responsive UI: Smooth and modern user experience across desktop and mobile devices.
---
Tech Stack

Frontend :
- Framework : React / JavaScript
- Styling : CSS /Bootstrap

Backend :
- Runtime : Node.js
- Framework : Express.js
- Database : MongoDB & Mongoose
- Authentication : JSON Web Tokens (JWT) / bcrypt
